# 화면 설계

배포 확인을 위한 조용한 작업실. 장식보다 실제 비교 화면에 면적을 배정한다.

- 바탕 #f6f7fb, 표면 #ffffff, 본문 #293042, 강조 #6859d9, 변경 #d7567a, 확인 #31836f
- DM Sans와 운영체제의 한글 글꼴. 좌측 정렬, 작은 보조 문구, 명확한 제목 계층
- 왼쪽에는 비교 페이지, 오른쪽에는 환경 A/B와 큰 비교 뷰어
- 화면 A/B를 처음부터 나란히 표시한다. 변화는 작은 상태 표시와 차이 영역으로 보여준다
- 슬라이더 핸들만 주요 상호작용의 시각적 강조로 사용한다
- 모바일은 사이드바를 접고 뷰어 위 페이지 선택기를 유지한다
- 빈 화면의 Forma 조형은 직접 작성한 CSS 데모이며 실제 결과와 구분한다

레이아웃:

```text
로고 / 워크스페이스                         도움말

            | 완료 / 변경 / 의도한 변경
            | 경로 선택              화면 크기
            | 화면 / 콘솔 / 네트워크 / SEO
            | A 스크린샷       B 스크린샷
            | 변화율              검토 표시
```
