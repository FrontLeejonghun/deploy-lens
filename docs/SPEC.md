# Deploy Lens v1 동작 명세

## 목표

기준·변경 사이트의 같은 경로를 같은 촬영 조건에서 비교한다. 기존 Dropshot 앱과 독립적인 신규 도구다. 저장소·배포에는 데모와 소스만 포함한다.

## 입력

- HTTP/HTTPS 기본 URL 2개, 경로 1~5개
- 데스크톱 1440×960, 모바일 390×844 중 하나 이상
- 선택적 CSS 제외 영역 최대 8개
- 픽셀 비교 색상 오차 0.01~0.5, 기본 0.1
- 최초 화면은 빈 상태이며 사용자가 샘플 실행 또는 새 비교를 시작한다

## 상태와 데이터

React의 report가 현재 비교의 정본이다. 각 페이지는 pending → running → done/error로 전이한다. 한 페이지 실패 후 다음 페이지는 계속 실행한다. 중단 시 진행 중 API를 abort하고 나머지를 cancelled로 표시하며 완료된 결과는 보관한다. 실행 중 새 비교와 기록 전환은 차단한다.

한 API 요청은 한 페이지의 두 환경을 별도 브라우저 컨텍스트로 촬영한다. 요청은 55초에 중단 신호를 보내며 Vercel 함수는 최대 60초다. 실패는 4xx 응답과 설명을 반환하고 UI는 해당 페이지의 실패 상태를 표시한다. 자동 재시도는 없으며 사용자가 설정을 확인하고 재실행한다.

비교 종료와 의도한 변경 표시 후 IndexedDB에 저장한다. 최근 12개 기록만 유지한다. 기록 삭제는 해당 브라우저의 복제본을 삭제한다. 저장 공간이 부족하면 안내하고 메모리에 남은 결과를 다운로드할 수 있다. 실행 도중 새로고침하면 진행 상태는 복구하지 않는다.

## 결과

- PNG 원본의 픽셀 차이와 퍼센트; WebP 표시 이미지 3장
- 기준 사이트에 없던 콘솔 메시지와 실패 요청
- 메타데이터 모든 값의 A/B 비교
- HTTP 문서 오류는 촬영 실패로 분리
- 동일 이미지라도 SEO 등 비시각 변경이 있으면 변경 감지로 표시
- 의도한 변경 표시는 페이지·화면 크기 단위이며 버그 해결을 뜻하지 않는다

## 접근성과 화면

모달은 native dialog로 포커스를 제한하고 Escape로 닫는다. 슬라이더는 range input이며 방향키를 지원한다. 모바일에서도 페이지 선택, 새 비교, 기록 확인, 중단 조작을 제공한다. 모션 감소 설정을 존중한다. 네트워크 실행 단계를 제외한 주요 조작은 즉시 반영한다.

## 데이터 경계

브라우저 로그인 정보, 사용자 프로필, 인증 쿠키를 사용하지 않는다. 공개 인터넷 목적지만 허용하고 private/loopback/link-local/multicast/reserved IP를 거부한다. 호스트를 검증한 뒤 같은 IP에 연결한다. GET/HEAD 외 요청은 차단한다. 소스 URL을 실행 가능한 HTML로 렌더링하지 않으며 보고서의 문자열은 HTML escape한다.

분산 레이트리밋·회원·결제·자동 스케줄·영구 클라우드 저장·동작 시나리오 검증은 v1 범위에서 제외한다.

## 수용 시나리오

- 샘플 3개 경로×2개 화면 크기에서 6개 결과 생성
- 홈과 요금제는 변경, 소개는 차이 0%
- 요금제의 404 요청·콘솔 오류·robots 변경 감지
- 동일 공개 URL 두 개는 같은 페이지에서 차이 0%
- 사설 IP, protocol-relative 경로, 잘못된 protocol, cross-site API 요청 거절
- 모바일 가로 넘침 없음, 페이지 전환과 슬라이더 키보드 조작 가능
- 의도한 변경 표시를 새로고침 후 복원
- 보고서에 화면 이미지가 포함되어 오프라인 확인 가능

## 추가된 촬영 품질·헤더 계약

- CSS 파일 실패, 적용되지 않은 link stylesheet, 웹폰트 실패, 촬영 영역 이미지 오류를 관측하고 경고한다. CSS 또는 폰트 경고가 있으면 선택된 화면을 "촬영 확인 필요"로 표시한다.
- Chromium 서버리스의 단일 프로세스 제약에 맞춰 A/B를 독립 브라우저 인스턴스로 순차 촬영한다.
- 인증·배포 보호용 헤더를 환경당 8개까지 입력한다. 이름·값은 CR/LF를 거절하며 전송 계층 헤더는 허용하지 않는다.
- 헤더는 실행 요청으로만 전달하며 report.settings에 포함하지 않는다. requiresHeaders 여부만 저장한다.
- 전용 프록시가 DNS를 검증하고, 헤더 요청은 자동 redirect 없이 가져온 후 browser에 응답한다. 새 origin에 원래 헤더를 부착하지 않는다.
- 401/403, 서버 브라우저 종료, 시간 초과, 인증서, DNS, CSS 선택자 오류를 구분한다.
- 보호된 샘플은 헤더 없이 거절되고 올바른 데모 헤더로 성공해야 한다. 다른 출처로 리다이렉트될 경우 헤더가 전달되지 않아야 한다.

## 전체 페이지 스크롤

문서를 10,000px까지 단계적으로 내려 지연 로딩을 유도하고 맨 위로 돌아와 전체 높이를 촬영한다. A/B 높이가 다르면 짧은 이미지를 흰색으로 채운 뒤 같은 좌표에서 픽셀 차이를 계산한다. 표시 이미지 압축률은 응답 크기에 따라 조정하며 원본 픽셀 차이 수치는 유지한다. 전체 응답이 Vercel 제한을 넘지 않도록 이미지 용량을 검사한다. 내부 스크롤 패널·iframe은 독립적으로 펼치지 않는다. 이전 첫 화면 기록은 이전 촬영 범위를 표시한다. 뷰어의 공통 스크롤 영역이 나란히 보기의 두 화면을 함께 이동시킨다.
